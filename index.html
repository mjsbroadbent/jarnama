Put Jarnama ads on your site

Attelkom Jarnama serves the banner ads seen across Irad's web, from 1990s dial-up pages to today's news sites. Add one script and a few empty boxes, choose a theme, and the network fills them.

Quick start

  1. Add the script once, near the end of the page, and give it the theme or themes your site should show.
  2. Put an empty div with class jarnama wherever an ad should go, with the size you want.
  3. That's it. Each box gets a random ad of that size from your themes. If there's no matching ad, the box stays hidden.
<!-- an ad box: put as many as you like -->
<div class="jarnama" data-size="728x90"></div>

<!-- once per page, before </body> -->
<script src="https://mjsbroadbent.github.io/jarnama/serve.js"
        data-theme="current local" defer></script>

One box, a different theme

A box can ask for its own themes instead of the page's. This puts a scam ad in the sidebar of an otherwise respectable page:

<div class="jarnama" data-size="300x250" data-theme="sketchy"></div>

Styling

The script puts a link and an image inside the box and leaves the look to you. A label and centring are usually enough:

.jarnama { margin: 1.5rem auto; text-align: center; }
.jarnama:empty { display: none; }
.jarnama::before { content: "Advertisement"; display: block;
  font: 11px sans-serif; text-transform: uppercase; color: #888; }
.jarnama img { max-width: 100%; height: auto; }

Themes

A theme decides which ads a box can show. Pick one era theme for the look your site should have, then add the types of advertiser you want. Separate codes with spaces, for example data-theme="dialup local".

Era themes (dialup, flash, current) set the look; the others set the kind of advertiser. Most ads carry both, so dialup local gives you 1990s small-business ads and current state gives you today's government notices. IradOne uses current state; the Talas Herald uses current local state.

Adding new ads

Ads are listed in campaigns.json. Each entry gives the file, size, themes, a link and alt text, and can have start and end dates or "active": false to pause it. The starter ads are built by tools/make_starters.py; see the repository for the toolkit.

Attelkom Jarnama is part of the Irad worldbuilding project. Irad is a fictional country, and every advertiser here is invented. Ad links lead to a placeholder page, never to a real site.
